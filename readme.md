# Internship Application Tracker

A Python + SQLite based application to manage internship applications.

## Features
- Add applications
- View applications
- Update application status
- Delete applications
- Search applications
- View statistics

## Technologies Used
- Python
- SQLite

## How to Run

1. Clone repository
2. Run:

python main.py
